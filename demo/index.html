Grammar cheat sheet (copy / paste) 
-- @viz: bar | line | area | scatter | pie | heatmap   (or any Flint template: waterfall, gauge, sankey...)
-- @x: category_or_date_column
-- @y: measure_column
-- @groupby: series_column            (-- @series: also works)
-- @value: measure_column             (heatmap colour)
-- @aggregate: sum | avg | min | max | count | first
-- @stack: true | false | stack_name
-- @zoom: inside,slider
-- @title: Chart title
-- @subtitle: Chart subtitle
-- @theme: powerbi-light | nyt | economist | swiss | ...
-- @semantic: col: Type, other: Type
-- @echarts_override: {"backgroundColor":"#fff"}
-- @flint: {"chart_spec":{"title":"Custom"}}

-- No annotations? The compiler infers: temporal -> x, first measure -> y, first category -> series, default bar/line.
